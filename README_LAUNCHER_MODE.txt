STARGATE WEBVIEW ANDROID - LAUNCHER MODE

This version can be selected as the tablet Home / Launcher app.

How to use on the tablet:

1. Install the APK.
2. Open the app once manually.
3. Enter your Stargate address and connect successfully.
4. Long press anywhere in the app if you need to change the address.
5. Go to Android Settings:
   Settings > Apps > Default apps > Home app
   or Settings > Home app
6. Choose Stargate WebView as the Home app.
7. Restart the tablet.

After restart, Android should open this app as the Home screen.
This is more reliable than BOOT_COMPLETED autostart because Android treats it as the launcher.

How to leave / change back:

If you need to return to the normal tablet launcher:
Settings > Apps > Default apps > Home app
Choose the original launcher again.

Important:
Different Android tablets have different names for this setting.
It may be called Home app, Default launcher, Default apps, or Launcher.
